## Description (paste as is)

Three complete Paper 1 Reading practice papers written for the NEW 2027 Cambridge IGCSE First Language English (0500) exam, each with full mark schemes.

From June 2027, Paper 1 has four compulsory 20-mark questions, a new 5-mark attitudes question (2b), 2-mark word-meaning questions and shorter writing targets. Past papers from earlier years no longer match this format. These practice papers do.

WHAT'S INSIDE
• 3 full practice papers (80 marks each, 240 marks in total)
• 9 original reading texts (fiction, articles, memoir and travel writing) across three themes: The Sea, Work and Challenge, Endings and Beginnings
• Question 1: comprehension questions on Text A, testing explicit and implicit meaning
• Question 2(a): 120-word summary task with a full list of creditable points
• Question 2(b): the new writer's attitudes question, with indicative answers
• Question 3: short answers with 2-mark word-meaning questions, plus the 200–250 word language task with detailed indicative content for each paragraph
• Question 4: extended response (letter, report and journal) with indicative content for every bullet
• Marking bands for the summary, language task and extended response
• A student score tracker that shows which skill to work on next
• Numbered paragraphs, so questions are easy to reference
