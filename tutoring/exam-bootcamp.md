## Session 1: Paper 1 Reading, Q1 and Q2 (90 min)
| Time | Activity |
|---|---|
| 0–10 | Warm-up: flashcards quiz ("Says or suggests?", "Summary rules") |
| 10–25 | Teach: Find → Prove → Phrase; the 5-step summary; attitude + evidence + explanation (Guide §02–03) |
| 25–55 | **Timed:** P1-2 Set 4, Q1 (20 min) + Q2(b) (7 min) |
| 55–80 | Mark live with the scheme; each student rewrites their weakest answer |
| 80–90 | Homework: P1-2 Set 4 Q2(a) summary (≤120 words), to be emailed before Session 2 |

## Session 2: Paper 1 Reading, Q3 and Q4 (90 min)
| Time | Activity |
|---|---|
| 0–10 | Summary feedback: show two anonymous examples, one strong and one that copies |
| 10–25 | Teach: swap test for word meanings; Choose → Zoom → Connect (Guide §04) |
| 25–50 | **Timed:** P1-2 Set 5 Q3 short answers + language task (25 min) |
| 50–65 | Peer-mark the language task with the band descriptors |
| 65–85 | Q4: three-column plan together for P1-2 Set 5 Q4 (speech); students write the opening |
| 85–90 | Homework: finish Q4 (250–300 words) |

## Session 3: Paper 2 Section A, directed writing (90 min)
| Time | Activity |
|---|---|
| 0–10 | Cards: "Repeat → Evaluate", "Questioning evidence" |
| 10–25 | Teach with the P2 ladder; read the P2-2 Task 7 model letter and its notes |
| 25–40 | **Timed:** P2-2 Task 5, Q1(a) (8 min) → mark together |
| 40–48 | Plan Task 5 Q1(b) using the planning frame (8 min, as in the exam) |
| 48–83 | **Timed:** write Q1(b), 250–350 words (35 min) |
| 83–90 | Self-check with the checklist; hand in for marking |

## Session 4: Composition + exam strategy (90 min)
| Time | Activity |
|---|---|
| 0–15 | Return marked Q1(b) with one target each |
| 15–30 | Teach: descriptive vs narrative, a quick read of one model (Comp) |
| 30–40 | Choose a title from Comp Set 4 or 5 and plan it (10 min) |
| 40–75 | **Timed:** write 350–450 words (35 min: shorter than the exam, to leave time for feedback) |
| 75–85 | Exam plan: timing cards for both papers, top-10 mistakes, the night before |
| 85–90 | Close: "What's the one thing you'll do differently in the exam?" Each student says it aloud |

**After the bootcamp:** mark the compositions and return them by email within 3 days with one written target each. Offer anyone who wants more a 2-lesson "final polish" top-up (440 AED).
