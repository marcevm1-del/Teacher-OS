# The 8-Lesson IGCSE 0500 Programme (term package, 1,600 AED)

Every lesson is 60 minutes, online or in person. Materials come from your own PassWithPurpose products, so lessons need almost no preparation. Print or screen-share the pages listed.

**Key:** Guide = Complete Exam Guide · P1 = Paper 1 Practice Pack · P2 = Paper 2 Directed Writing Pack · Comp = Composition Pack

**The rhythm of every lesson:** 5 min review homework → 15 min teach one method → 30 min guided practice → 10 min independent attempt + set homework.

---

## Lesson 1: Diagnose (and hook the parent)
**Goal:** find the student's weakest skills and show the parent a clear plan.
- 5 min: What do they find hardest? What grade are they aiming for? When is the exam?
- 25 min: **P1 Set 1, Q1 (a)–(e)** under light time pressure (12 min), then mark together.
- 20 min: **P1 Set 1, Q3 word meanings + (b)** and a 5-minute attempt at the language task on paragraph 2 only.
- 10 min: Fill in the progress report below. Name the **two skills** you'll fix first.
- **Homework:** P1 Set 1 Q2(a) summary (≤120 words).
- **After the lesson:** send the parent the progress report (template below) the same evening. This is what gets parents to renew and recommend you.

## Lesson 2: Paper 1 Q1: says or suggests
- Teach: Guide section 02 (Find → Prove → Phrase). Use the SAYS/SUGGESTS sort from the free briefing's starters.
- Practise: P1 Set 2, Q1 (a)–(e) together, then (f)–(i) alone.
- Mark with the P1 Set 2 scheme; the student rewrites their weakest answer.
- **Homework:** P1 Set 3 Q1 complete (20 min timed).

## Lesson 3: Q2 summary and the new 2(b)
- Review last week's summary: count words, highlight any copied phrases.
- Teach: Guide section 03 (5-step method) + the attitude + evidence + explanation structure.
- Practise: P1 Set 2 Q2(a) summary together; the student does Q2(b) alone.
- **Homework:** P1 Set 3 Q2(a) and (b).

## Lesson 4: Q3 word meanings and the language task
- Teach: Guide section 04 (Choose → Zoom → Connect) using the market worked example.
- Practise: P1 Set 2 Q3 word meanings (swap test), then plan the language task together, one paragraph each.
- The student writes the second paragraph alone (10 min).
- **Homework:** full P1 Set 3 Q3 language task (200–250 words).

## Lesson 5: Q4 extended response
- Teach: Guide section 05 (Mine → Stretch → Voice) + form conventions table.
- Practise: three-column plan for P1 Set 2 Q4 together; the student writes the opening + first bullet.
- **Homework:** P1 Set 2 Q4 complete (250–300 words).

## Lesson 6: Paper 2 directed writing: evaluate, don't repeat
- Teach: P2 Form Toolkit + "repeating → evaluating" ladder.
- Practise: P2 Task 1: answer 1(a) together; map both texts with the planning frame.
- Read the model speech and its "Why this scores highly" notes. The student then plans their own position (different from the model).
- **Homework:** P2 Task 1 Q1(b) (or Task 2 if they need letter practice).

## Lesson 7: Composition
- Teach: Comp descriptive **or** narrative toolkit (whichever the student will choose in the exam; decide together).
- Practise: sentence upgrade workshop (Comp); then plan one Set 1 title on the planning sheet.
- Read the matching model composition.
- **Homework:** write the composition (350–450 words, 45 min).

## Lesson 8: Mock review and exam plan
- Before the lesson: the student sits a full timed paper at home (P1 Set 3, or P2 Tasks 3/4 + a Comp title).
- In the lesson: go through the marked mock and fill in the P1/P2 score tracker.
- Exam plan: Guide timing plans + top 10 mistakes + exam-week checklist.
- **Close:** *"Here's what we've improved and what's next. I'd recommend another 8 lessons focused on [X] before the exam. Shall I keep your Tuesday slot?"*

## Renewals and referrals: where the money compounds
- **Renew at Lesson 6**, not Lesson 8. Parents decide before the package ends: *"We have two lessons left. Shall I reserve the same slot for next term?"*
- **Ask for a referral** after the Lesson 4 progress report (template in `tutoring-kit.md`).
- **Exam season (Apr–May):** invite every current student's classmates to the 4-session bootcamp (600 AED each, max 6). Use P1 Sets 1–3 and P2 Tasks 1–4 as the bootcamp material.
